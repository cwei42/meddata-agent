# Evaluation on public datasets

Every answer the agent gave on public datasets, graded by hand: ✓ correct, ½ partly correct, ✗ wrong or no answer. The grades, the charts and this page are generated by [make_eval_chart.py](make_eval_chart.py).

The 10 questions were written on 2026-11-25, before any of these datasets was downloaded or opened. Datasets 06 and 07 were never used for tuning. Datasets 03 to 05 were also used during development.
